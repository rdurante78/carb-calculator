# Carb & Insulin Calculator

Installable web app (PWA) that converts foods and grams to raciones (1 R = 10 g carbohydrate) and works out rapid-insulin units from a set plan, with a pre-meal glucose correction.

- Raciones: Fundación para la Diabetes table (Serafín Murillo), with hospital values where they differ.
- Plan values (ratios, snack rule, correction bands, sensitivity factor) are editable in the Settings tab and saved on the device.
- Works offline once installed (service worker).

Open https://rdurante78.github.io/carb-calculator in Chrome on Android and choose "Install app".

A calculation aid only; it does not replace the medical team. Always check the result before injecting.
